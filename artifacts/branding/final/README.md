- 딥그린: `#123D2E`
- 졸업 골드: `#C5A04E`
- 다크모드 반전색: `#F7F5EE` (골드는 유지)
- `logo-master.svg`: 수정하지 않은 확정 원본

- `favicon.svg`: 시스템 다크모드 자동 반전
- `favicon.ico`: 16/32/48/64px 호환 파비콘
- `apple-touch-icon.png`: 180px 딥그린 배경 홈 화면 아이콘
