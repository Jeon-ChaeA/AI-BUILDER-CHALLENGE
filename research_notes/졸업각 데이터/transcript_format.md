# 국민대 성적 표기와 이수구분 라벨

조사일: 2026-10-03

**범위 주의**
- ON국민 포털 화면은 로그인해야 볼 수 있어서 **실제 화면 라벨은 공개 출처로 확인하지 못했다.**
- 대신 공식 **성적증명서 서식**을 확인했다. 2026 요람 학사규정 (별지 제17호 서식 제97조), PDF p.210, 인쇄면 197. 2023 요람에도 같은 범례가 있다(PDF p.186).
- 성적·재수강·성적포기 관련 학사안내와 수강신청 종합안내의 문구도 함께 정리했다.
- 학과 홈페이지(cs.kookmin.ac.kr)에는 성적표 표기를 설명한 페이지가 없다. 아래 내용은 모두 대학 단위 출처다.

## 1. 성적 등급과 평점

| 등급 | 평점 | 백분율 점수 (학사안내 성적 / 학사규정 제61조) |
|---|---|---|
| A+ | 4.5 | 95–100 |
| A0 (A°, 성적증명서에는 "A") | 4.0 | 90–94 |
| B+ | 3.5 | 85–89 |
| B0 (B°, "B") | 3.0 | 80–84 |
| C+ | 2.5 | 75–79 |
| C0 (C°, "C") | 2.0 | 70–74 |
| D+ | 1.5 | 65–69 |
| D0 (D°, "D") | 1.0 | 60–64 |
| F | 0.0 | 59 이하 |

**같은 등급이 출처마다 다르게 적혀 있다.**
- 학칙 제30조와 학사규정 제61조 표는 `A0`, `B0` 식이다.
- 학사안내 성적 페이지는 `A°`, `B°` 식이다.
- 성적증명서 하단 범례는 `A`, `B`, `C`, `D`다. 원문: "A+:4.5 A:4.0 B+:3.5 B:3.0 C+:2.5 C:2.0 D+:1.5 D:1.0 F:0.0 P:Pass N:Non-Pass R:재수강 W:성적포기"

→ 파서는 `A0`, `A°`, `A`를 모두 4.0으로 같게 처리해야 한다.

**급제·낙제 기준**
- 학칙 제30조: "D0급 이상을 급제로 하고, F급은 낙제로 한다."

**평점 외 기호**
- 학사규정 제61조④: "P/N(합격/불합격) 및 I(유보)학점을 둘 수 있으며". 국민대 표기는 **"NP"가 아니라 "N"(Non-Pass)**이다.
- **R** = 재수강. 수강신청 종합안내 p.6 원문: "기 취득 성적은 성적표에 [R] 표기됨"
- **W** = 성적포기. 학사안내 성적포기 원문: "성적증명서에 W(Withdraw)로 표기됨"
- **I** = 유보. 규정상 존재하지만 부여 조건은 "따로 정한다"로만 되어 있고 세부 내용은 찾지 못했다.

## 2. 평점평균 계산 (학사안내 > 성적)

- 원문: "학업성적의 평점평균은 [(수강신청 교과목별평점×교과목별 학점)의 총합)]÷수강신청 총 학점]으로 하며 소수점 이하 셋째자리에서 반올림한다."
- 원문: "P/N방식으로 평가되는 교과목은 평점평균 산정 시 제외하되 취득학점에는 포함."
- 백분율 환산 원문: "55 + (평균평점 x 10)"
- 성적증명서에는 학기별로 `학점계 / 평점평균 / 백분위`가, 맨 아래에 `총 취득학점 / 총 평점계 / 총 평점평균 (…/4.5) / 백분위 점수 (…/100)`가 나온다.

## 3. 성적증명서의 이수구분 라벨과 코드 (별지 제17호 서식)

서식 하단 '<이수구분별 취득학점- 실이수(중복인정)>' 블록에 적힌 라벨을 원문 그대로 옮겼다. 괄호 안 영문자는 서식에 적힌 약어다.

| 라벨 | 코드 | 2023학번 해당 여부 |
|---|---|---|
| 교양필수 | A | 옛 체계 |
| 기초공통 | B | 옛 체계 |
| 전공필수 | C | 옛 체계. 2023학번 필수과목도 이수구분은 '전공선택'이다 |
| **전공선택** | **D** | **해당** |
| 교양선택 | E | 옛 체계 (2014 이전) |
| **일반선택** | **F** | **해당** |
| 교양기초 | K | 옛 체계 (2004–2014) |
| 계열교양 | L | 옛 체계 |
| 학부기초 | M | 옛 체계 |
| **기초교양** | **V** | **해당** |
| 전공기초교양 | X | 옛 체계 (2020 개편으로 전공선택에 흡수) |
| **핵심교양** | **Y** | **해당** |
| **자유교양** | **Z** | **해당** |
| 교직 | H | 교직 이수자만 |
| 복수전공 | J | 해당 시 |
| 부전공 | G | 해당 시. 서식에 `00.0(00.0)` 형식으로 표시된다 |

**다전공 블록** ('<다전공 취득학점- 실이수(중복인정)>')
- 제2전공: 계열교양(PL), 전공기초교양(PX), 학부기초(PM), 전공(PN)
- 제3전공: QL, QX, QM, QN
- 연계·융합전공: 기초(RM), 전공(RN)

**표 본문 열 구성**은 `이수구분 | 교과목명 | 학점 | 성적`이고 3단으로 배치된다. 학기 구분 줄은 "0000 년도 0학기"다.

- `verify`: 성적증명서 표 본문의 '이수구분' 칸에 한글 라벨(예: "전공선택")이 나오는지, 약어(예: "D")가 나오는지는 빈 서식만으로 확정할 수 없다. 실제 발급본 한 장으로 확인해야 한다.

- 성적포기 신청: "ON국민포털 – 학사서비스 – 성적 정보 – 성적 포기 신청" (학사안내 성적포기)
- 개인 시간표: "ON국민 포털 > 학사서비스 > 수강정보 > '개인수업시간표 조회'" (수강신청 종합안내 p.2)
- **화면의 열 이름, 내보내기 형식(엑셀/PDF), 성적 표기 방식은 공개된 페이지에서 찾지 못했다.**

## 5. 파서 구현 메모 (사실 정리, 추론 포함 시 표시)

- 등급 정규화: `A0|A°|A → 4.0`, `B0|B°|B → 3.0`, `C0|C°|C → 2.0`, `D0|D°|D → 1.0`
- `P`: 학점 인정, 평점 제외
- `N`: 평점 제외. 학점 미인정은 추론이다 `verify`
- `F`: 학점 미인정, 평점 분모에 포함
- `R`이 붙은 이전 성적과 `W`(성적포기)는 취득학점과 평점에서 모두 제외한다.
- 동일과목 판정: 교과목 코드 7자리 중 앞 5자리가 같으면 같은 과목이다(학사안내 재수강).
