## 2. 우선 항목별 정리

| 항목 | 결과 |
|---|---|
| **수강철회** | 학부 학사일정에 '수강철회' 항목이 **없다.** 비슷한 기간은 "2학기 수강신청 변경/포기 기간" 2026-09-01(화) ~ 09-07(월)인데 이미 지났다. 학사규정 제49조(수강신청 포기 및 최저학점)는 "삭제" <2015.04.01.>로 되어 있다. 학기 중 철회 대신 쓸 수 있는 제도는 **성적포기**이고, 2026-2 신청기간 2026-09-14(월) 10:00 ~ 09-17(목) 23:59도 이미 끝났다(교무팀 안내문, 학과 공지 #2848). |
| **동계 계절학기 수강신청** | 2026-11-24(화) ~ 11-26(목). 등록은 12-01 ~ 12-03, 수업은 12-22 ~ 2027-01-13. 계절학기 최대 6학점(학칙 제32조④). 장바구니 등 세부 일정은 아직 공지되지 않았다. 작년 학과 공지는 「2025학년도 동계 계절학기 안내」(25.10.15, #2720)와 「수강신청 안내」(25.11.17, #2740) 순서로 올라왔다. |
| **졸업신청 / 졸업사정** | 정규 졸업에는 학생이 내는 '졸업신청'이 **없다.** 8학기 이상 재학하면 자동으로 졸업사정 대상이 된다(교무팀 「졸업사정 대상자 확인 안내」). 학생이 신청하는 것은 조기졸업뿐이고, 2026-2 조기졸업 신청 9/18 ~ 9/23은 이미 지났다(학과 공지 #2861). **2027년 2월 졸업 사정 일정은 2026-10-03 현재 공지되지 않았다.** 아래 §3의 작년 일정을 참고하라. |
| **휴학·복학** | 2027학년도 1학기 휴학·복학 신청 기간은 2027-01-04(월) ~ 01-22(금)이다. |
| **2027-1 수강신청** | 2027-02-11(목) ~ 02-24(수). 학년별 신청일과 장바구니 일정은 수강신청 종합안내가 나와야 알 수 있다. 2026-1 종합안내는 학과에 2026-01-05(#2765)에 공지되었다. |
| **2027-1 수강정정** (변경/포기) | **공지되지 않음.** 2027년 3월 일정이 학사일정에 없다. |
| **2학기 종강** | 학사일정에 '종강일' 항목이 **없다.** 원문에 있는 것은 기말시험 12-08 ~ 12-14(수업 15주차), 보강 12-15 ~ 12-21, 동계방학 시작일 12-22다. |
| **성적 공시** | 2026-12-15(화) ~ 12-28(월). 이의신청/정정은 12-23 ~ 12-28. |
| **2027-1 개강** | **공지되지 않음.** 2027년 3월 일정이 없다. 추정 날짜는 넣지 않았다. |
| 학위수여식 | 2026학년도 전기 학위수여식 2027-02-17(수) |
