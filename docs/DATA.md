# 졸업각 데이터 가이드

소프트웨어학부 2023학번 기준 데이터. 위치는 `app/public/data/`이고, 브라우저는 `/data/*.json`으로 읽고 서버는 파일로 읽는다.
수정한 뒤에는 `cd app && npm run validate:data`를 돌린다. 오류가 있으면 종료 코드 1이다.

## 파일

| 파일 | 쓰는 곳 | 내용 |
|---|---|---|
| `categories.json` | 전체 | 이수구분 enum, 표기 별칭, 성적 환산·미산입 규칙 |
| `requirements.json` | FR-02 진단·경고, FR-03 검증 | 졸업요건 수치, 필수과목, 수강학점 한도, 재수강 규정, 수동 확인 항목. 판정 항목마다 `evidence`(원문 + URL) |
| `curriculum.json` | FR-03 로드맵 후보 | 과목 목록(코드·학점·학년·학기) |
| `calendar.json` | FR-04 일정 | 학사일정과 노출 조건(`trigger`) |

## 진단 엔진(②)이 알아야 할 규칙

- **과목 매칭**: 학수번호 앞 5자리가 같으면 같은 과목이다(원문 규칙, `requiredCourses.codeMatchPrefixLength`). 예: 소프트웨어적사고 1143704 = 1143702.
  코드가 없으면 `name`과 `aliases`로 비교한다. 기초교양도 앞 5자리로 비교한다(졸업요건표는 6자리 `000200`, ON국민 성적 화면은 7자리 `000200D`). 비교 전에 과목명 끝의 `(공학인증)`, `(ABEEK)`를 지우고 띄어쓰기·로마숫자(Ⅰ/I)를 정규화한다.
- **성적 화면 형식**: ON국민 로그인 → 학사서비스 → 성적정보 → **전체학기 성적조회(학부)** 화면의 열은 `학년도 | 학기 | 이수구분 | 교과목(코드) | 교과목명 | 분반 | 학점 | 등급 | 평점`이다(`categories.transcriptScreen`). 이수구분은 한글로 나오고, 등급은 `A+`, `A0` 형식이다. 이 캡처에서는 전공 교과목이 `일반선택`으로 표시됐으므로(전공 미배정 등 원인 미확인), 필수·전공 여부는 이수구분 라벨이 아니라 과목 목록(`requirements`, `curriculum`)으로 판정한다.
- **재수강**: 성적 화면의 `[R]` 표기는 확인하지 못했다. 표기에 기대지 말고 같은 과목이 여러 학기에 나오면 최근 학기 행만 센다(`requirements.retakePolicy.dedupFallback`). 이렇게 하면 `[R]` 표기가 어떻게 나오든 같은 결과가 나온다.
- **입력 안내 문구**: 앱 입력 화면에 "ON국민 → 학사서비스 → 성적정보 → 전체학기 성적조회(학부) 화면을 캡처하거나 복사해 붙여넣으세요"처럼 메뉴 경로를 넣으면 학생이 헤매지 않는다.
- **학부별 코드 차이**: 같은 이름의 과목도 학부가 다르면 코드가 다를 수 있다(예: S-TEAM Class는 소프트웨어학부 0367203, 인공지능학부 1622901). 이 데이터는 소프트웨어학부 기준이다.
- **전공필수**: 별도 이수구분이 아니라 "전공선택 중 필수 지정 과목"이다. `requiredCourses.items`에 있는 과목이면 인식된 이수구분이 전공선택이어도 전공필수로 센다.
- **택1 그룹**: S-TEAM Class와 사제동행세미나는 하나만 이수해도 필수 충족이다(`oneOfGroups`). 필수 15개, 41학점은 이 그룹을 하나로 센 값이다.
- **미산입**: F, N은 학점에서 뺀다. 국민대 표기는 NP가 아니라 **N**이고 NP는 별칭으로만 받는다. F는 평점 평균에 0점으로 들어가고, P와 N은 평점에서 뺀다. 재수강 전 성적(`[R]`)과 성적포기(`W`)는 학점·평점 모두 뺀다(`retakePolicy`, `categories.grades`). 등급 표기는 A0=A=A°로 같게 처리한다.
- **평점**: 전학년 성적 평점평균 **2.0 이상**이 졸업 조건이다(`gpa.min`). 평점 계산에서 F는 0점으로 넣고, NP·P와 재수강 전 성적(`[R]`)은 뺀다.
- **초과 학점**: 이수구분별 최저학점을 넘긴 학점은 일반선택으로 인정한다(`overflowRules`). 교양은 합계 50학점(상한)을 넘으면 초과분이 졸업학점 136에 들어가지 않는다(`liberalArtsCap.overCapRule`).
- **졸업 학기 조건**: 8학기 이상 등록해야 한다(`minRegisteredSemesters`). 휴학 학기는 등록 학기가 아니다.
- **판정하지 않는 것**: `manualCheck`(졸업인증, 졸업논문, 핵심교양 영역별 3학점, 심화/부전공/다전공)는 "학과 사무실 확인 필요"로 안내만 한다.

## 로드맵(③·⑤)이 알아야 할 규칙

- 학기당 최대 수강학점은 **19학점**이다. 계절학기는 **6학점**까지다. 직전 학기 평점이 3.75 이상이면 **22학점**까지 된다. 성적경고 연속 2회면 14학점이다.
- 휴학 후 복학하면 휴학 직전 학기 성적으로 초과 신청 여부를 판단한다. 계절학기 성적은 직전 학기 평점에 넣지 않는다.
- **개설 학기 제약**: `curriculum.json`의 `offered`(`"1"`/`"2"`/`"all"`)에 맞는 학기에만 과목을 배치한다. 코드로 검증할 수 있다. 예: 다학제간캡스톤디자인, 운영체제, 컴퓨터네트워크, 데이터베이스는 1학기에만 열리고, 컴퓨터구조·이산수학은 2학기에만 열린다. 알고리즘, 자료구조, C++프로그래밍, 객체지향프로그래밍은 전학기다.
- **수강 학년**: `years`는 수강 가능한 학년 범위다. 김국민이 남은 2027-1, 2027-2 학기는 4학년이므로 `years`에 4가 들어 있는 과목만 추천한다.
- 학점·개설 학기는 K* 스마트멘토 화면(로그인 필요)에서 팀원이 캡처한 값이다. 화면에 교과적용년도가 없어서 현재 개설 기준일 수 있다. 2023학번 졸업요건표와 다르면 필수과목은 `requirements.json`을 따른다. 필수 표시가 붙은 15개는 졸업요건표의 필수과목 15개와 일치함을 확인했다.
- 필수과목은 `year`·`semester`가 확정이다. 부족한 필수과목을 우선 배치한다.
- 교양은 재학 중 50학점, 학기당 8학점(핵심+자유교양)이 상한이다. 상한을 넘겨 듣는 교양은 졸업학점에 도움이 되지 않으니 로드맵에서 교양을 더 추천하지 않는다.
- "남은 정규 학기"는 8학기에서 이미 등록한 학기 수를 뺀 값이다. 휴학 학기는 세지 않는다. 예: 김국민(23학번, 휴학 2학기, 3학년 2학기)은 6학기를 등록했으므로 남은 정규 학기는 2개(2027-1, 2027-2)다.
- 실전프로젝트Ⅰ·Ⅱ는 `countsTowardMajor66: "conditional"`이다. 역량기반 요건을 실전프로젝트로 채우면 전공 66학점에 들어가지 않는다.

## 일정(⑤)이 알아야 할 규칙

- 날짜는 `YYYY-MM-DD`, `end`는 **마지막 날을 포함**한다.
- `.ics`는 종일 일정이다. `DTSTART;VALUE=DATE:`에 start를, `DTEND;VALUE=DATE:`에 **end 다음 날**을 쓴다.
- 오늘 이전에 끝난 일정(`end < 오늘`)은 코드에서 뺀다. 데이터에서는 빼지 않는다.
- `trigger` 값: `hasCreditShortage`, `hasNextSemesterCourses`, `isGraduatingSemester`, `always`, `none`.
  `none`은 화면에 보이지 않는다. 진단 결과가 trigger 조건을 만족하는 일정만 보여 준다.
- D-day는 시작일 기준으로 계산하고, 기간 중이면 "진행 중, 마감까지 D-n"으로 보여 주는 것을 권장한다.

3. ON국민 성적 화면의 이수구분 표기와 학수번호 표시 여부. `categories.json`의 `aliases`는 추정이다. 팀원의 실제 성적 화면으로 확인한다.
4. 졸업인증: 졸업요건 이미지의 선택지 10가지와 2026-06-11 시행 규칙의 3가지가 다르다.

7. N(Non-Pass)의 학점 처리: 조문을 찾지 못해 학점 미인정으로 추정했다.
