## 이번 점검에서 고친 것

- 마감 일정의 D-day가 스크롤하기 전에는 모두 "D-0"으로 읽혔다. 숫자 카운트업 연출을 없앴다.
- 스크롤 전 요소를 숨기는 연출 때문에, 스크롤하지 않는 전체 페이지 캡처에서 결과가 비어 보였다. 자동화 표시(`navigator.webdriver`)가 꺼진 Playwright 브라우저에서도 같은 문제가 재현돼서, 스크롤에 묶인 숨김을 아예 없앴다. 결과는 그려진 직후 1초 안에 모두 보인다(ScrollTrigger 제거).
- 인쇄 화면에서 졸업 노드의 "136/136학점"이 흰 글씨라 보이지 않았고, 하단 안내문이 본문과 어긋나 있었다. 인쇄 리포트 머리글(학과·학번, 기준 학기, 진단일)도 넣었다.
- 탭이 뒤에 있으면 첫 화면이 반투명한 채로 남았다. GSAP 지연 보정을 끄고, 2.5초 뒤 강제로 끝낸다.
- 이용권 사용 중일 때 휴대폰 폭에서 상단 표시가 두 줄로 넘쳐 로고를 덮었다. 좁은 화면에서는 날짜를 숨긴다.
- PRD의 버튼·탭 이름이 화면과 달랐다('샘플 학생으로 체험' → '샘플 학생' 등). PRD를 화면에 맞췄다.
- 사업 모델이 화면에 없었다. '왜 졸업각인가'와 '요금' 섹션을 첫 화면 아래에 넣었다.

## 2차 점검 (PRD 대조 심사·코드 리뷰·보안 리뷰 에이전트)

같은 날 PRD↔코드 대조, 코드 리뷰, 보안 리뷰를 각각 별도 에이전트로 돌리고 찾은 것을 고쳤다. 운영 사이트에서 진단 → 결제 → 재진단을 다시 돌려 확인했다(진단 14.5초, 결과 가려짐 0, 콘솔 오류 0).

- 로드맵: AI가 주어진 학기보다 길게 짜면 검증을 통과해 졸업 시기가 한 학기 늦게 나올 수 있었다. 학기 수를 서버에서 막는다.
- 로드맵 품질: 규칙은 지켜도 한 학기 일반선택 빈칸이 6학점을 넘으면 '보완할 점'으로 한 번 더 요청한다(검증 기록에 보인다).
- FR-02: 항목마다 상태 글자가 보이게 했다("진행 중 · 52학점 부족").
- FR-05: 결제 완료 안내가 진단 진행 문구에 덮이던 것, 체험 전에 연 이용권 창이 "다 썼어요"라고 하던 것.
- FR-11: 가입 직후 로그아웃하면 가입 폼이 다시 뜨던 것.
- 보안: 작은 gzip 본문이 15MB로 풀려 서버를 멈출 수 있던 것(압축 본문 거절, 경로별 크기 제한), AI 호출 전체 상한, CSP·X-Frame-Options·HSTS, 비동기 bcrypt.
- 안정성: GSAP CDN이 느릴 때 첫 화면이 멈추던 것, 서비스 워커가 재배포 뒤 옛 파일을 내주던 것, 없는 API 주소에 HTML이 나가던 것(이제 JSON 404).
- 영어 모드: 표 수정 값이 번역된 글자로 저장되던 것, 샘플 학생 숫자로 고정된 요약.
