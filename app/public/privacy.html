개인정보 처리방침

시행일 2026년 10월 3일

1. 처리하는 정보

성적 진단올린 성적 화면 캡처나 붙여넣은 텍스트, 적어 주신 희망 사항. 서버에 저장하지 않고 분석에만 써요. 진단 결과는 이용자 브라우저 화면에만 있어요.
회원가입(선택)이메일, 비밀번호, 로그인 세션. 비밀번호는 원문을 저장하지 않고 bcrypt 해시로만 저장해요.
브라우저 저장소무료 체험 사용 여부, 이용권 만료일, 화면 테마(라이트/다크) 선택. 이용자 브라우저(localStorage)에만 있고 서버로 보내지 않아요.
접속 기록서버 운영과 요청 제한을 위해 웹 서버에 IP 주소, 접속 시각, 요청 주소가 남아요.

성적 화면을 올리기 전에 이름과 학번은 가려 주세요. 졸업 진단에는 필요하지 않아요.

2. 이용 목적

  • 성적 인식, 졸업요건 진단, 수강 계획과 문의 메일 작성
  • 회원 로그인 유지
  • 과도한 요청 같은 서비스 남용 방지

3. 처리를 맡기는 곳

Google (Gemini API)성적 캡처·텍스트·희망 사항을 분석해요. Gemini API 이용약관에 따라 처리돼요.
Oracle Cloud Infrastructure서비스 서버를 운영하고 회원 정보를 보관해요.

4. 보관 기간

  • 성적 데이터: 보관하지 않아요. 분석이 끝나면 서버에 남지 않아요.
  • 로그인 세션: 30일이 지나거나 로그아웃하면 지워요.
  • 회원 정보: 회원이 삭제를 요청할 때까지 보관해요.

5. 이용자의 권리

이용자는 언제든 자기 회원 정보의 열람, 정정, 삭제를 요청할 수 있어요. 브라우저에 저장된 체험·이용권 정보는 첫 화면 아래 '체험 초기화'나 브라우저 설정에서 바로 지울 수 있어요.
